# Bus Rush Duel

A mobile bus-jam duel: clear your bus adda before your opponent clears theirs, and throw goats, freezes and chai stalls at each other.

Play: https://zubairs-gallery.github.io/bus-rush-duel/

- **Play a friend**: create a room, send the 4-letter code, race on the same lot.
- **Quick match**: race a random player, or a bot if nobody is free.
- **Practice**: race Bilal the bot on easy, normal or hard.

Single-file prototype (`index.html`): canvas 2D, vanilla JS, Supabase Realtime for online play.
